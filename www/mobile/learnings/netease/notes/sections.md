# 区块与卡片定位表

各页面的区块与卡片，用**区块的无障碍名 + 元素的 role + name** 三元组定位。

## 主页（view: home）

| 区块 | role | name | 备注 |
| --- | --- | --- | --- |
| 每日推荐 | region | 每日推荐 | 承接每日推荐歌单 |
| 为你推荐 | region | 为你推荐 | 歌单卡的主要出处 |
| 排行榜 | region | 排行榜 | 榜单项的出处 |
| 推荐歌手 | region | 推荐歌手 | 歌手卡的出处 |
| 新碟上架 | region | 新碟上架 | 专辑卡的出处 |

## 卡片与条目

| 元素 | role | name | 所在区块 |
| --- | --- | --- | --- |
| 歌单卡 | listitem | 歌单名称 | 为你推荐 / 每日推荐 |
| 榜单项 | listitem | 榜单名称 | 排行榜 |
| 歌手卡 | link | 歌手名称 | 推荐歌手 |
| 专辑卡 | listitem | 专辑名称 | 新碟上架 |
| 区块标题 | heading | 区块名称 | 与区块同名 |

歌单卡与榜单项都用 `listitem`，靠**区块**区分，靠 **name** 区分具体是哪一个。
同名歌单出现在多个区块时，用区块限定：

```
region "为你推荐" → listitem "华语热歌"
```

## 外壳（常驻）

| 元素 | role | name | 备注 |
| --- | --- | --- | --- |
| 迷你播放条 | region | 迷你播放条 | 常驻底部 |
| 播放开关 | button | 播放 / 暂停 | 在迷你播放条内 |
| 底部导航 | navigation | 主导航 | |
| 导航项 | button | 主页 / 广播 / 资料库 / 搜索 | 在主导航内 |
| 返回按钮 | button | 返回 | 顶部栏，仅在有历史时出现 |

底部导航项同时带 `current` 标记，表示当前所在根视图。

## 资料库（view: library）

| 元素 | role | name |
| --- | --- | --- |
| 入口列表 | list | 资料库入口 |
| 入口项 | listitem | 播放列表 / 喜欢的音乐 / 云盘 / 最近播放 / 听歌排行 |

## 定位写法

- 单个元素：`role="listitem" name="华语热歌"`
- 限定区块：`region "为你推荐"` 内的 `role="listitem" name="华语热歌"`
- 一组同类：区块内所有 `role="listitem"`

## 命名约定

无障碍名要**跟着内容走**，不要跟着位置走：

- 歌单卡：歌单名
- 歌手卡：歌手名
- 榜单项：榜单名
- 按钮：动作名（`播放`、`暂停`、`返回`）

这样名字在数据更新后依然成立；用「第 3 个」这种命名则不会。
