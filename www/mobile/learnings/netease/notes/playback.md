# 播放状态契约

播放状态**由查询得到，不由界面像素推测**。ADR-0003 §4 规定：状态可查询，转移可命名。

## 迷你播放条的无障碍语义

迷你播放条是常驻区块：

```
region "迷你播放条"
  image "光年之外 封面"
  text "光年之外"
  text "邓紫棋"
  button "播放"
```

读法：

| 字段 | 来源 | 规则 |
| --- | --- | --- |
| 曲目名 | image 的无障碍名 | 去掉结尾的「封面」二字 |
| 歌手 | 区域内除曲目名外的非空文本 | 曲目标题之外的文本节点 |
| 播放开关 | button 的无障碍名 | 暂停时叫「播放」，播放中叫「暂停」 |
| 进度 | `player.state()` | 迷你播放条不承载进度 |

空载状态：曲目名为「未在播放」，此时视为**没有在播放**。

播放按钮的名字是**状态本身**：按钮叫「播放」说明当前暂停着，叫「暂停」说明正在放。
所以「点它」和「它现在的状态」是同一个信号，不需要另设一个状态标记。

## 字段来源与降级顺序

```
1. player.state()      —— 首选，ADR-0003 §4 的契约
2. 迷你播放条语义      —— 降级，覆盖曲目/歌手/播放开关
3. 契约错误            —— 两者都不可用
```

`player.state()` 返回 `{ playing, trackName, artist, position, duration }`（字段名允许 `name` 代替 `trackName`）。
降级路径下 `position` 与 `duration` 为 `null`：进度条不在语义树里（它是装饰性的），不猜。

## 动作

| 动作 | 语义 |
| --- | --- |
| 播放 | 点 button「播放」 |
| 暂停 | 点 button「暂停」 |
| 切换 | 点当前那个按钮（名字本身就是状态） |

`togglePlayback()` 返回 `wasPlaying` 与 `nowPlaying` 两个字段：前者是点击前的状态，后者是点击后的推演结果。

## 约束

- 不通过直接改 DOM 来「模拟」状态变化。
- 不用进度条宽度反推时间位置（那是像素，不是语义）。
- 播放状态没有暴露成可查询的名字时，宁可返回 `null`，也不要给一个看起来像真值的猜测。
