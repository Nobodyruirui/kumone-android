# 稳定定位器总览

网易云移动端渲染层的元素定位，**只有一种合法形式：role + name**。

```
role="button" name="播放"
```

- `role`：元素在无障碍树里的角色（button / link / listitem / region / image / text / heading …）。
- `name`：元素的无障碍名（`aria-label` 优先，其次可见文本）。

两者共同构成界面契约。语义树由 `Mobile.snapshot()` 给出，所以「看得见的名字」就是「能点的名字」。

## 为什么不用临时引用

语义快照里每个可交互节点都带一个短标识。它**只在这一次快照里有效**：界面一重建（换页、重新渲染、列表刷新），标识就会重新分配。把它写进知识包，等于把一次性的观测结果当成长期契约。

知识包里出现的每一条定位规则，都必须是**下一次快照仍然成立**的那一种。

## 为什么不用像素坐标

坐标随设备像素比、状态栏高度、字体缩放而变。同一份知识在另一台机器上就会指错地方。坐标是最后手段，不是常规手段。

## 优先级

1. **role + name 精确匹配** —— 首选。
2. **限定区块后精确匹配** —— 同名元素存在时，先把范围收窄到某个区块（region 的无障碍名）。
3. **role + name 包含匹配** —— 只在区块内部使用，用来匹配一组同类元素。

匹配顺序永远从「最窄的范围」开始：先找区块，再在区块里找元素。

## 未命中与歧义

| 情况 | 错误码 | 处理 |
| --- | --- | --- |
| 条件为空（没给名称） | `KUMONE_EMPTY_RESULT` | 补参数，不要重试 |
| 一个都没命中 | `KUMONE_NOT_FOUND` | 换区块或换层级，不要原地重试 |
| 命中多个 | `KUMONE_AMBIGUOUS_TARGET` | 加区块限定，或换一个更具体的名字 |

两种失败都是 `permanent`：重试没有意义，要换策略。

## 被禁用的定位形式

- 临时引用（快照里的短标识）
- 像素坐标
- DOM id 选择器（id 是实现细节，改版即失效）
- 用 CSS class 做定位（class 属于样式层，不属于界面契约）

class 只允许用于**非定位性的样式判断**。

## 语义树片段长什么样

```
region "为你推荐"
  listitem "华语热歌"
  listitem "深夜电台"
region "迷你播放条"
  image "光年之外 封面"
  text "光年之外"
  text "邓紫棋"
  button "播放"
```

读法：先认区块（region），再认区块里的角色与名字。列表项的名字就是可点的名字。

## 配套工具

| 工具 | 用途 |
| --- | --- |
| `openPlaylistByName(name, options)` | 按名称打开一个歌单 |
| `listPlaylists(options)` | 列出当前界面的歌单/卡片 |
| `currentPlayback()` | 读播放状态摘要 |
| `togglePlayback()` | 播放/暂停切换 |

工具内部走的是同一套规则：先按 role+name 命中语义树，再把命中的节点交给动作层。
