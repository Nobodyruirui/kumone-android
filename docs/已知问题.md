## 14. ego 巡检查出的两处缺陷（已修）
> 2026-10-30 用 ego-lite 把每个页面都走了一遍（12 个视图：主页 / 广播 / 搜索三种态 / 资料库 / 歌单详情 / 全屏播放页 / 队列），逐页查错误卡、残留骨架、缺无障碍名的控件、模型拿不到 ref 的控件、缺 alt 的图片、导航高亮、运行时异常。查出两处真缺陷：

| 缺陷 | 现象 | 状态 |
|---|---|---|
| 播放引擎在「服务成功但地址为空」时崩溃 | 网易云对 VIP / 无版权的歌会「成功返回但 url 为空」，播放引擎读 `last.data.level` 时抛 `Cannot read properties of null`，整条播放链断成未处理的 rejection | ✅ 已修：把这种情况判为「这一档音质不可用」并继续降级，最终错误由音源解锁兜底决定；补了 3 条回归断言 |
| 沉浸式页面底部导航没有高亮 | 未登录点「资料库」弹出的扫码页、队列页，底部导航**一个高亮都没有** —— 用户点了「资料库」却看不到它被选中 | ✅ 已修：新增 `body.m-focus`（扫码登录与队列藏起导航与迷你条，顶栏保留给返回箭头），与全屏播放页的 `body.m-np` 同一套外壳机制 |
