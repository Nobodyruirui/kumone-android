# 移动端不保留桌面外壳：侧边栏与常驻完整播放条移除

Status: accepted

移动端渲染层不包含左侧边栏导航，也不包含带进度条、音量滑块与音质下拉的常驻完整播放条。导航改由底部导航承担；当前曲目信息由迷你播放条承担，点开展开为全屏播放页；音质选择移入全屏播放页或设置。

原因：Apple Music 的手机端观感正是由"无侧边栏、无常驻进度条与音量滑块、只有迷你条 + 全屏页"这两点撑起来的，保留桌面外壳会让整体观感始终差一层；而手机上的音量滑块与音质下拉属于桌面鼠标交互的遗留，在触屏上无对应手势。

## Consequences

音质、音量这类原本常驻在播放条上的控制项，需要在全屏播放页或设置面板中有落点，否则功能会无处安放。
