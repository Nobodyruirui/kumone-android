# 移动端渲染层独立于上游原版渲染层，不就地改造上游代码

Status: accepted

上游原版渲染层（`www/app.js`）是桌面取向的单文件移植产物，本项目新增一套面向手机的移动端渲染层（`www/mobile/`），两者并存而非就地改造前者。

原因有三：就地改造会让 diff 淹没在上游代码里、无法分辨哪些是本项目改动；上游随时可能更新，独立目录便于 rebase；本轮只覆盖主页与全屏播放页，独立目录让"只做两页"这件事在结构上成立。

## Considered Options

- 就地改写 `www/app.js` 的各个渲染函数 —— 改动集中，但与上游代码纠缠、丧失可回退性。
- 组件化重写为完整结构 —— 收益超出本轮范围，引入的抽象没有第二个使用方。
