# 02: 封面加载一致且有兜底

**What to build:** 所有封面**大小一致、速度一致**，加载失败会自动换个 CDN 节点重试，出现时是淡入而不是蹦出来；迷你播放条显示真实封面。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 图片地址按用途带缩略尺寸参数（卡片 220 / 迷你条 96 / 详情头图 400 / 全屏封面 500 / 广播卡 300）
- [ ] 加载失败自动换 `p1..p4` 节点重试，最多 3 次，仍失败才落占位图
- [ ] 列表封面懒加载 + 异步解码，出现时淡入
- [ ] 迷你播放条与全屏封面优先加载（不等懒加载）
- [ ] 归一化层与服务层各有一条断言

## Comments

已完成（2026-10-31）。取证：实测网易云图片**原图是 1024×1024**（几百 KB），40px 的迷你条也在下它 → 真机上「时快时慢、有的出不来」。缩略参数实测有效（`?param=96y96` → 96×96）。
实现：界面零件层的封面工厂统一带缩略尺寸（卡片 220 / 迷你条 96 / 详情头图 400 / 全屏封面 500 / 广播卡 300）；加载失败自动换 `p1..p4` 节点重试 3 次（记录 `data-cdn-first` 便于排查）；列表封面懒加载 + `decoding=async` + 淡入；迷你条与全屏封面 eager。
证据：探针断言缩略参数、https、懒加载、异步解码、换节点重试全部成立（`npm run test:detail:view`）。
真机项：验收清单 3.32 / 3.33。
