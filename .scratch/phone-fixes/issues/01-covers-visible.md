# 01: 封面看得见

**What to build:** 用户在真机上滑动主页、搜索结果、推荐歌手时，**歌曲封面**能像歌单封面一样正常显示；万一某个地址真的失效，看到的是一个干净的占位块，而不是裂图图标。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 网易云接口返回的歌曲封面地址（实测为 `http://`）在归一化后变成 `https://`，歌单 / 专辑 / 歌手 / 头像同理
- [ ] 空地址不会被补成一个无效的 `src`（不出现裂图）
- [ ] 图片加载失败时显示占位块而不是浏览器默认的裂图
- [ ] 归一化层新增断言：协议改写、尺寸参数追加、空值处理
- [ ] 界面零件层提供统一的封面元素工厂，各视图不再各自拼 `<img>`
- [ ] 加密基线自测与真实接口连通自测仍全绿

## Comments

已完成（2026-10-31）。取证：`.scratch/probe-covers.js` 统计出**歌曲封面 100% 是 `http://`、歌单/专辑封面是 `https://`**；App origin 是 `https://localhost` 且 Capacitor 默认不允许混合内容 → 歌曲封面被拦。
实现：归一化层新增图片地址规整（空值→null、`http:`→`https:`、追加尺寸参数），曲目/歌单/专辑/歌手/头像全部走它；界面零件层新增统一封面元素工厂（负责规整 + 加载失败占位），各视图不再各自拼 `<img>`。
证据：`npm run test:normalize` 全绿（含 9 条新断言）；`npm test`（加密基线）与 `npm run test:live`（6/6）仍全绿。
真机项：待装新 APK 后确认（验收清单 3.20）。
