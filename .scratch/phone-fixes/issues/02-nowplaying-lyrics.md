# 02: 播放页有歌词

**What to build:** 用户在全屏播放页能**看到这首歌的歌词**：有逐字歌词时是卡拉 OK 扫光效果，没有逐字时回退成整行高亮，完全没有歌词时看到明确提示而不是空白。当前唱到的那一行自动滚动到中间，翻译行显示在原文下方。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 歌词请求能取回逐字歌词数据（内核只做这一处增量，其余内核逻辑不动）
- [ ] 歌词解析是纯函数：整行歌词、逐字歌词、翻译行三样都能解析成统一的「行」结构，且可在 Node 里逐条断言
- [ ] 播放页有「歌词」开关，能在封面视图与歌词视图之间来回切
- [ ] 逐字歌词走卡拉 OK 扫光（当前行 + 行内进度），整行歌词走整行高亮
- [ ] 当前行随播放进度自动居中滚动
- [ ] 没有歌词时显示明确提示
- [ ] 切换歌曲时歌词随之切换，旧的歌词不残留
- [ ] 视图探针（Edge headless）断言歌词面板真的渲染出来了

## Comments

已完成（2026-10-31）。内核只加了一处增量：歌词请求带 `yv=-1`（不带就没有 `yrc` 字段）。
新增歌词解析纯函数模块（整行 / 逐字 / 翻译三合一，逐字优先，元信息行如「作词 : xxx」会被拦掉 —— 实测逐字歌词第一行就是这种）。
播放页：点「歌词」按钮或点封面切换封面视图 ↔ 歌词视图；逐字走卡拉 OK 扫光，整行走整行高亮；当前行自动居中滚动；没有歌词显示「暂无歌词」。
证据：真接口实测 8 首歌里 2 首有逐字、6 首只有整行 → 两条路径都被覆盖；`npm run test:lyrics` 27 条断言全绿；播放页探针新增 7 条歌词断言后仍全绿。
真机项：扫光手感与滚动（验收清单 3.24 / 3.25）。
