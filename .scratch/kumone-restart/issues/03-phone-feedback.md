# 手机反馈 · 转场、播放与系统栏

2026-11-21

| 反馈 | 改动与验证 |
| --- | --- |
| 边缘返回时闪过白块 | 页面先同步就位。转场只移动不透明的内容层，返回复用之前的页面和滚动位置。浏览器验证了手势取消、完成、快速返回和减弱动效。 |
| 迷你条和全屏切换 | 展开向上、收起向下。390×844 和 360×740 的搜索播放路径均通过，列表返回到原来的 420 px。 |
| 找不到歌单和收藏 | 左上角「我的」现在有文字，抽屉第一项为「我创建的歌单」。底部「收藏」进入收藏歌单和专辑。两个入口的浏览器探针通过。 |
| 缺封面、找不到歌词 | 播放器在曲目数据缺图时补查详情。迷你条和全屏共用曲目封面。顶部有歌词和队列入口，歌词加载失败可以重试。匿名检查《成都》（赵雷）确认搜索和曲目详情均有封面，封面 HTTP 200，歌词接口返回带时间戳的歌词。 |
| 状态栏颜色和返回键遮挡 | Android 容器为状态栏、刘海、导航栏和键盘预留空间，系统栏显示深色图标。调试包已编译，ADB 暂无设备，待真机检查。 |
| 后台一曲结束就停 | 临时网络失败时重试同一首，手动暂停取消重试。引擎测试覆盖自然切歌、重复结束事件和失败恢复，锁屏后自然续播待真机检查。 |
