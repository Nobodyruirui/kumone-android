# 01: 歌词真的出得来 + 我的内容齐活

**What to build:** 用户刷到任何一首歌都能看到它的歌词；能把自己的歌单建起来、把歌加进去、把专辑收藏起来；播放页能切顺序 / 单曲循环。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 整行歌词的歌也能显示（接口给的是 `{version, lyric}` 对象，取 `.lyric`）
- [ ] 「作词 / 作曲 / 填词」这类元信息行不进正文
- [ ] 播放页有「加入歌单」与「播放模式」按钮
- [ ] 播放模式循环：顺序 → 单曲循环 → 列表循环 → 随机，并写进引擎
- [ ] 「加入歌单」用底部抽屉：能选歌单、能直接新建并加入
- [ ] 歌单 / 专辑 / 歌手详情的每一行有「+」按钮
- [ ] 资料库有「收藏的专辑」入口；我的歌单页有「新建歌单」
- [ ] 专辑页有「收藏」按钮，能收藏也能取消
- [ ] 服务层单测 + 视图探针全绿
