# 02: 设计令牌与外壳（ego 风格）

**Blocked by:** 01: 目录归位与入口接线

**Status:** ready-for-agent

## 现状与缺口

- 设计令牌已集中到 `www/mobile/css/tokens.css:37-95`，且**已按 ego 风格重写**：白底画布 `--canvas: #f4f4f6`（`:46`）、卡片面 `--surface: #ffffff`（`:47`）、常规描边 `--line: #e3e3e7`（`:42`）、强描边 `--line-strong: #0a0a0a`（`:43`）、文字三档 `--ink` / `--ink-2` / `--ink-3`（`:39-41`）、角色色五个（`:54-58`）、卡片圆角 16px 与小件 10px（`:70-71`）、粗体主字 800/700 与 300 斜体副标（`:61-66`）。
- 外壳样式在 `www/mobile/css/shell.css`（379 行）：吸顶栏 `#m-header`（`:56`）、内容大标题 `.m-display`（`:110`）、区块标题与**细斜体副标** `.m-section-note`（`:129-135`）、底部导航 `#m-nav`（`:139`，当前项用重墨 `--ink` + 700 字重，`:173-174`，**不引入颜色**）、迷你播放条 `#m-mini`（`:179`，白卡面 + 1px `var(--line-strong)` 黑描边 + `--radius-card`，`:190-193`）、吐司 `.m-toast`（`:370`）。
- **卡片本体已补齐**：`.m-card`（`shell.css:299-305`）定义了白面 + 1px 描边 + `--radius-card` + `--shadow-card` + padding，角色色变体只改背景色（`:308-318`）。令牌里的 `--shadow-card`（`tokens.css:84`）因此有了消费方。
- 结构层已接线：`www/mobile/core/shell.js` 的 `buildHeader()`（`:43`）、`buildNav()`（`:54`，四项 主页/广播/资料库/搜索，见 `:21-26` 的 `TABS`）、`buildMini()`（`:66`）、`boot()`（`:149`）。
- **具体缺口一**：**语义契约的自动检查只覆盖 `button`**。`test/guard-design.mjs:100-108` 的正则只匹配 `createElement('button')` / `el('button')`；`link`、`tab` 等可交互元素缺 `aria-label` 不会被拦下。而 ADR-0003 §2 的要求是「可交互元素一律用语义标签并带 `aria-label`」。
- **具体缺口二**：**裸 CSS 选择器仍然存在，且没有被任何闸门拦住**。`www/mobile/core/shell.js:94` 的 `document.querySelectorAll('#m-nav .m-tab')` 与 `:127` 的 `document.querySelector('#m-mini-line > i')` 属于「实现内部面」——按 ego 规则应当允许，但**规则本身没有划边界，也没有登记机制**（详见 ticket 14）。
- **具体缺口三**：底部导航与迷你播放条在 `shell.js` 中被 `boot()` 无条件构建（`:63`、`:77`），全屏播放页进入时**没有隐藏逻辑**（ADR-0002 要求隐藏）；该能力归 ticket 09。
- **具体缺口四**：`shell.css` 里 `.m-skeleton`（`:335-348`）已有骨架动画，但主页仍是**永久**占位，没有「加载中 / 出错 / 空」三态区分（归 ticket 08）。
- **具体缺口五**：还没有对「视图层不得出现硬编码的颜色/字号/圆角」的自动检查（`tokens.css:11` 已把这条写成规则，但没被执行器），归 ticket 14。

## 要求

- 把设计令牌集中保持在 `www/mobile/css/tokens.css` 一处：画布、卡片面、次级面、常规描边、强描边、文字三档、角色色、字号与字重、圆角、尺寸与安全区、阴影、字体栈、动效。
- 让 ego 视觉语言成立：白底画布、1px 描边、大圆角卡片、克制单色系；**停止使用品牌红** `#fa2d48`，导航选中态与强调一律用重墨与黑描边表达。
- 让「颜色即角色」成立：策展=橙 `#f2c489`、我的=黄 `#f5dea9`、自动=蓝 `#a9cbe8`、工具=粉 `#f3c3c0`、中性=灰 `#dcdcdc`，每个颜色只承载一种含义；新增区块必须先确定角色色，不允许引入新颜色。
- 让粗体主字配细斜体副标的字重对比成立：主字 700–800（`--fw-display: 800` / `--fw-title: 700`），副标 300 斜体（`--fw-note: 300` + `font-style: italic`）。
- 保留打包进安装包的 Inter 可变字重拉丁子集（`tokens.css:14-35`，含斜体变体），中文回退到系统字体，声明顺序保持拉丁优先；字体不依赖网络。
- 让底部导航四项（主页/广播/资料库/搜索）渲染在屏幕底部，图标与文字齐全，选中态用重墨 + `aria-current="page"`。
- 让吸顶标题渲染在内容区顶部：滚动前内容里是大标题，滚动后顶栏出现居中小标题，回顶后恢复。
- 让迷你播放条常驻底部导航之上，含封面、歌名、艺人、播放/暂停按钮与顶部一条极细进度线。
- 保持 `.m-card` 本体与角色色变体的分层（形状与描边继承本体，颜色只改背景），让新增区块有可依附的载体。
- 让视图层不出现硬编码的颜色、字号与圆角：一律引用 `var(--*)` 令牌。
- 把语义契约的自动检查从「只查 button」扩展到全部可交互元素（`link` / `tab` / `switch` 等），归 ticket 14 承接闸门实现，本 ticket 负责给出元素清单。

## 明确不做什么

- 不做深色主题，也不做跟随系统明暗；本轮 ego 白底是唯一主题（深色变体见 spec 的 Deferred D4）。
- 不在 `www/mobile/css/` 之外新增样式文件；令牌与外壳各一处，不散落。
- 不在内容区组件（主页卡片、资料库列表、歌单详情）里实现数据逻辑，那属 ticket 08/10。
- 不实现全屏播放页的隐藏逻辑，本 ticket 只保证外壳自身存在且正确。
- 不引入新的颜色作为装饰；新颜色只能作为角色色引入。

## Comments

令牌集中在 `www/mobile/css/tokens.css`，外壳样式在 `www/mobile/css/shell.css`。

**本轮按 ego 基线重写后的实测结论与偏离项**：

1. **标题已改，下游标签也已同步。** 本 ticket 原名「设计令牌与移动端基础样式」，现改为「设计令牌与外壳（ego 风格）」。下游 ticket 07 的 `Blocked by` 原先仍写着旧标题，现已一并更新为新标题 —— 依赖边（谁依赖谁）没有变化，只换了标签名。
2. **视觉基线已切换，结论是「已就位、无需再返工」。** `tokens.css` 已是 ego 取值：白底 `#f4f4f6`、白卡 `#ffffff` + 1px `#e3e3e7`、强描边 `#0a0a0a`、卡片圆角 16px、小件 10px、五个角色色、字重对比 800/700 与 300 斜体。品牌红 `#fa2d48` 与 spec 里原先写的 `#FA243C` **两个值都不再使用**，也不存在「仓库里两套红」的问题 —— 因为这一层直接换掉了整套色板。
3. **偏离项（已修）：`.m-card` 本体。** 此前只有 `shell.css:308-318` 的五种 `data-role` 背景变体、没有本体；现已补上 `shell.css:299-305`（白面 + 1px 描边 + `--radius-card` + `--shadow-card` + padding），`--shadow-card` 有了消费方。
4. **偏离项：全屏播放页的外壳隐藏未做。** `shell.js` 的 `boot()`（`:149-165`）无条件构建导航与迷你条，隐藏逻辑归 ticket 09。
5. **偏离项：「语义契约」闸只查 button。** `test/guard-design.mjs:100-108` 的正则只匹配 `createElement('button')` / `el('button')`，`link` / `tab` 等可交互元素的 `aria-label` 缺失不会被拦。扩展该闸归 ticket 14，本 ticket 只需给出元素清单。
6. **偏离项：「裸 CSS 选择器」没有闸也没有边界。** `shell.js:94` / `:127` 的选择器作为实现内部用法是合理的，但 ADR-0003 §2 只写了「禁止裸 CSS 选择器」而没有区分「模型定位面」与「实现内部面」。落地时要先把边界定下来，否则这条规则不可执行（ticket 14）。
7. **偏离项：「视图层禁硬编码」目前只是一句注释。** `tokens.css:11` 写了规则，但没有执行器；构建期自测归 ticket 14。
8. Inter 仍是 Google Fonts 的可变字重拉丁子集（400–800，含一份 300–500 斜体变体），只覆盖拉丁与数字，中文交给系统字体；字体文件随包安装，不依赖网络。字体栈见 `tokens.css:88-90`。
9. 深色是唯一主题的说法已作废：现在 ego 白底是唯一主题。
10. 还没做的：内容区组件的**数据接线**（卡片本体已有，但主页与资料库仍是占位），那些属于 ticket 08 主页与 ticket 10 资料库。
